Sơ đồ kiến trúc hệ thống mẫu — Hạ tầng on-premise/hybrid (SSIS)v2

Phiên bản cập nhật sau đánh giá điểm yếu: bổ sung dual-core switch, IDS/IPS, caching layer, HAProxy dự phòng, cách ly VLAN IoT/máy in, patch & vulnerability scan, cost dashboard, RTO/RPO cho DR.

Thay đổi so với v1:
  • Network: Core switch đơn → Dual-core switch (MLAG/Stack), loại bỏ single point of failure lớp mạng
  • Security: Thêm IDS/IPS inline sau firewall; DMZ nâng cấp thành WAF + Reverse Proxy; tách riêng VLAN40 cho máy in/IoT không route trực tiếp sang Server VLAN
  • Reliability: HAProxy từ 1 instance → Active/Passive (VRRP)
  • Performance: Thêm Redis caching layer giảm tải cho VM dịch vụ
  • Operational: Thêm khối Patch Management & Vulnerability Scanning
  • Cost: Thêm Cost Dashboard đo usage/VM, cảnh báo tài nguyên idle; storage có chính sách lifecycle tự động
  • DR: Ghi rõ chỉ số RTO/RPO thay vì chỉ mô tả chung chung
Security Reliability Performance Cost Optimization Operational Excellence

Cách đọc sơ đồ: nhãn (NEW) đánh dấu các thành phần vừa được bổ sung so với v1. Đường liền = traffic chính; đường đứt tím = luồng giám sát; đường đứt xanh lá = backup/replication sang DR.
Đây vẫn là bản mẫu tổng quát — khi áp dụng thực tế cho SSIS, cần điền IP/VLAN ID cụ thể và xác nhận lại RTO/RPO theo yêu cầu nghiệp vụ thực (PowerSchool/PaperCut có thể cần RPO ngắn hơn).
