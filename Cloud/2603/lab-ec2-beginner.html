Làm Quen Với Amazon EC2

Hiểu các khái niệm cốt lõi của EC2 và tự tay khởi chạy máy chủ ảo đầu tiên trên AWS — dành cho người mới bắt đầu, không cần kinh nghiệm trước.

1

EC2 là gì?

▾

EC2 (Elastic Compute Cloud) là dịch vụ cho phép bạn thuê máy chủ ảo (gọi là instance) chạy trên hạ tầng của Amazon. Thay vì phải mua máy tính vật lý, cài đặt, bảo trì phần cứng — bạn chỉ cần vài phút để có một máy chủ sẵn sàng sử dụng, trả tiền theo thời gian dùng.

Ví dụ dễ hình dung: EC2 giống như thuê một căn hộ trong một tòa chung cư khổng lồ (data center của AWS). Bạn chọn loại căn hộ (instance type: nhỏ/vừa/lớn), chọn nội thất có sẵn (AMI: hệ điều hành + phần mềm cài sẵn), chọn ổ khóa cửa (key pair để SSH vào), và ai được phép gõ cửa (security group: tường lửa). Bạn trả tiền theo giờ/giây sử dụng, và có thể trả lại căn hộ bất cứ lúc nào (terminate instance).
⚠
Lưu ý chi phí: EC2 tính phí theo thời gian instance đang chạy (running), kể cả khi bạn không làm gì. Luôn nhớ Stop hoặc Terminate instance sau khi thực hành xong để tránh phát sinh phí ngoài ý muốn.

Các khái niệm cốt lõi

▾
Khái niệmGiải thích
InstanceMột máy chủ ảo cụ thể đang chạy trên AWS.
AMI (Amazon Machine Image)"Bản sao lưu" của hệ điều hành + phần mềm cài sẵn, dùng làm khuôn mẫu để khởi tạo instance (ví dụ: Amazon Linux 2023, Ubuntu 22.04).
Instance TypeCấu hình phần cứng (số vCPU, RAM, mạng) — ví dụ t2.micro, t3.small.
Key PairCặp khóa public/private dùng để SSH đăng nhập vào instance mà không cần mật khẩu.
Security GroupTường lửa ảo, kiểm soát traffic ra/vào instance theo port và giao thức (giống bảo vệ ở cổng chung cư).
EBS (Elastic Block Store)Ổ đĩa lưu trữ gắn vào instance, tồn tại độc lập với vòng đời instance (không mất dữ liệu khi Stop).
Elastic IPĐịa chỉ IP tĩnh, không đổi kể cả khi bạn Stop/Start lại instance.
Region / AZRegion là khu vực địa lý (vd: ap-southeast-1 - Singapore); AZ (Availability Zone) là các trung tâm dữ liệu tách biệt vật lý trong cùng Region.

Ghi nhớ nhanh: AMI = bản thiết kế → Instance = máy chủ thực tế được tạo ra từ bản thiết kế đó.

Instance Type: chọn loại nào?

▾

Instance type được đặt tên theo dạng [họ][thế hệ].[kích thước], ví dụ t3.micro.

Họ (Family)Tối ưu choVí dụ dùng thực tế
T — BurstableWorkload nhẹ, không liên tụcWeb server nhỏ, môi trường học/test
M — General purposeCân bằng CPU/RAMỨng dụng backend thông thường
C — Compute optimizedCPU mạnhXử lý batch, encoding video
R — Memory optimizedRAM lớnDatabase, cache trong bộ nhớ
✓
Cho người mới bắt đầu: t2.micro hoặc t3.micro nằm trong AWS Free Tier (750 giờ/tháng miễn phí trong 12 tháng đầu) — lựa chọn lý tưởng để thực hành.
4

Thực hành: Khởi chạy EC2 instance

▾

Mục tiêu: Khởi chạy một EC2 instance chạy Amazon Linux, kết nối qua SSH, và cài một web server đơn giản.

1

Vào EC2 Console và khởi chạy instance

Console → EC2 → Launch Instance. Đặt tên (vd: lab-instance-01), chọn AMI Amazon Linux 2023, chọn instance type t2.micro.

2

Tạo Key Pair mới

Chọn "Create new key pair" → đặt tên lab-key → chọn định dạng .pem (Mac/Linux) → tải về và lưu cẩn thận (không thể tải lại lần 2).

3

Cấu hình Security Group

Cho phép SSH (port 22) từ IP của bạn, và HTTP (port 80) từ 0.0.0.0/0 nếu muốn truy cập web server sau này.

4

Launch instance và chờ trạng thái Running

Sau khi bấm "Launch Instance", chờ khoảng 1-2 phút để trạng thái chuyển từ pending sang running.

5

Kết nối SSH vào instance

Lấy Public IPv4 từ Console, chỉnh quyền file key rồi kết nối:

chmod 400 lab-key.pem
ssh -i lab-key.pem ec2-user@<PUBLIC_IP>
6

Cài đặt web server (Nginx) để kiểm tra

sudo dnf update -y
sudo dnf install nginx -y
sudo systemctl start nginx
sudo systemctl enable nginx

Mở trình duyệt và truy cập http://<PUBLIC_IP> — bạn sẽ thấy trang chào mừng của Nginx.

7

Dọn dẹp: Stop hoặc Terminate

Sau khi thực hành xong, vào Console → chọn instance → Instance State → Stop (tạm dừng, vẫn giữ EBS) hoặc Terminate (xóa hẳn) để tránh phát sinh phí.

🔒
Best practice bảo mật: Không nên mở port 22 (SSH) cho 0.0.0.0/0 trong môi trường thực tế — chỉ nên giới hạn theo IP cụ thể hoặc dùng AWS Systems Manager Session Manager để tránh mở port SSH ra internet.
5

Thực hiện bằng AWS CLI

▾

Toàn bộ quy trình trên cũng có thể thực hiện bằng CLI (region: ap-southeast-1):

# Tạo key pair
aws ec2 create-key-pair --key-name lab-key \
  --query 'KeyMaterial' --output text > lab-key.pem
chmod 400 lab-key.pem

# Khởi chạy instance (thay ami-id và security-group-id phù hợp region)
aws ec2 run-instances \
  --image-id ami-0xxxxxxxxxxxxxxxx \
  --instance-type t2.micro \
  --key-name lab-key \
  --security-group-ids sg-xxxxxxxx \
  --region ap-southeast-1 \
  --tag-specifications 'ResourceType=instance,Tags=[{Key=Name,Value=lab-instance-01}]'

# Kiểm tra trạng thái instance
aws ec2 describe-instances --filters "Name=tag:Name,Values=lab-instance-01" \
  --query 'Reservations[].Instances[].[InstanceId,State.Name,PublicIpAddress]' \
  --output table

# Dừng và xóa instance khi xong
aws ec2 stop-instances --instance-ids i-xxxxxxxxxxxxxxxxx
aws ec2 terminate-instances --instance-ids i-xxxxxxxxxxxxxxxxx
